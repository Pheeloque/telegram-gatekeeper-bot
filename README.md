# telegram-gatekeeper-bot

Telegram-бот для модерации групп: хранит отдельный чёрный список каналов для каждой группы и автоматически удаляет пересланные из них сообщения.

## Как пользоваться

1. Добавьте бота в группу и дайте ему права администратора (право удалять сообщения).
2. Напишите боту в личку `/start` — увидите список групп, в которых вы администратор, и выберите нужную.
3. В меню группы:

   - **➕ Добавить канал** — пришлите `@username` канала, его ID или просто **перешлите любое сообщение из канала**. После этого пересылки из канала в группе начнут удаляться.
   - **📋 Чёрный список** — показать список запрещённых каналов.
   - **➖ Удалить канал** — удаление: выберите канал из списка; после удаления вы остаётесь на этом экране, можно удалять несколько подряд.

Бот также уведомляет в группе о каждом удалённом сообщении (с названием канала и отправителем, если это доступно).

## Что важно знать про ID каналов

- Канал можно добавить по числовому ID в том виде, в каком его показывает Telegram (например `1234567890`), — бот сам приведёт его к полному виду.
- По ID канал проверяется через `getChat`: если бот не состоит в канале, проверить его не получится, и канал сохранится по ID без названия. Название и `@username` подставятся автоматически после первой пересылки из него (в личку или в группу).
- Если прислать пересылку — она имеет приоритет: бот берёт канал из поля `forward_origin`, остальной текст игнорируется. Пересылка **не из канала** будет отвергнута.

## Требования

- Go 1.27+;
- бот, созданный через `@BotFather`;
- права администратора в группе и право удалять сообщения у бота;
- управлять настройками может только администратор группы.

## Локальная установка

```bash
cp .env.example .env
# вписать TELEGRAM_BOT_TOKEN

go mod tidy
go run ./cmd/bot
```

### Переменные окружения

| Переменная | Обязательная | По умолчанию | Описание |
|---|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | — | токен от `@BotFather` |
| `STORAGE_PATH` | нет | `data.db` | путь к SQLite-файлу |
